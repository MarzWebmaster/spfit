🔑 Authentication

SPFit support 2 kaedah auth:

1. JWT Bearer Token — Authorization: Bearer <token> (dapat dari login)

2. API Key — x-api-key: spfit_xxxxx (untuk bot/automation)

API key auth auto-set role = Admin dan user ID = negative number (synthetic).
